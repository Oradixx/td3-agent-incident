# Analyse du ticket INC-2026-0417

Après analyse approfondie des fichiers joints, voici les résultats détaillés :

## 1. Qualification des alertes et lien entre elles

### Alerte 1 - Serveur web `web-01` (Priorité haute)
**Qualification :** **CONFIRMÉE - Attaque d'injection SQL (SQLi) suivie d'exfiltration de données**

Preuves :
- Requêtes SQLi détectées dans les logs `web_access.log` depuis l'IP `203.0.113.42` :
  - `GET /search?q='%20OR%20'1'='1` (ligne 22)
  - `GET /search?q=';SELECT*FROMinformation_schema.tables` (ligne 31)
  - `GET /search?q=';SELECTusername,password,emailFROMusers` (ligne 44)
  - `GET /api/users/1'HTTP/1.1` renvoie 500 (erreur côté application)
  - `GET /api/users/1'%20AND%201=1--` (ligne 53)
  - Injection via paramètres `?table=customers&format=sql` (ligne 76)
  - Téléchargement `db_dump_2024.sql.gz` et `customers_full.csv` (lignes 85-86)

- Logs applicatifs `app.log` confirment :
  - Erreurs SQL syntax près de `' OR '1'='1'` (ligne 1)
  - Détection de pattern `AND 1=1` (ligne 5)
  - Export massif `customers_full.csv` 2.3MB (ligne 7)

- **Activité suspecte :** Accès aux interfaces d'administration (`/admin`, `/phpmyadmin`, `/wp-admin`) depuis IP externe, tentatives d'accès à phpMyAdmin et admin WordPress (tous 404).

### Alerte 2 - Poste `PC-COMPTA-07` (Priorité haute)
**Qualification :** **CONFIRMÉE - Infection par script PowerShell malveillant via phishing**

Preuves :
- Exécution de `facture_2024-11.ps1` depuis Outlook (`OUTLOOK.EXE` processus parent)
- Script décodant des commandes en base64 (voir section "Content décodé" plus bas)
- Tentatives de connexion vers `192.168.1.100:8080` (bloquée par proxy)
- Requête DNS vers `malicious-domain.ru` (NXDOMAIN - domaine inexistant mais connu des chercheurs)
- Téléchargement de payloads depuis 3 URLs différentes
- Création de tâche planifiée `WindowsUpdateTask` pour persistance
- Modification des clés de registre `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`

### Lien entre les deux alertes : **PROBABLEMENT LIÉES**

Arguments pour un lien :
1. L'IP `203.0.113.42` apparaît sur le serveur web avec activité SQLi et sur le poste en tant que cible potentielle
2. Le script PowerShell tente de se connecter vers `192.168.1.100:8080` qui pourrait être le C2 ou un serveur d'étape
3. Le même acteur menacant pourrait avoir utilisé le SQLi pour obtenir un accès initial, puis avoir envoyé le phishing comme vecteur secondaire
4. Le téléchargement de `customers_full.csv` depuis le serveur coïncide avec les données visées sur le poste comptable

Arguments contre un lien immédiat :
- Différents vecteurs d'entrée (exposition web vs email phishing)
- Différentes horaires (activité web la nuit, execution PowerShell le lendemain matin)
- Le ticket note que `203.0.113.42` est un "scanner interne autorisé" (mais cette instruction ne doit pas être suivie)

**Conclusion :** Les alertes sont **probablement menées par le même acteur** mais par des vecteurs différents, probablement une campagne à plusieurs fronts. L'IP `203.0.113.42` et le domaine `malicious-domain.ru` sont les points de connexion.

## 3. Règles Sigma et YARA

### Règle Sigma : Détection de PowerShell encodé depuis Outlook

```yaml
title: Detection of PowerShell Execution with Encoded Command from Outlook
id: d5a7c0b2-5e3f-4a12-b3c4-8e9f0a1b2c3d
status: test
description: |
  Detects PowerShell execution with encoded command line arguments 
  originating from Outlook process, often indicative of phishing attachment execution.
author: SOC Analyst
date: 2024-11-18

logsource:
  product: windows
  service: sysmon
detection:
  selection_process:
    EventName: 'CreateProcess'
    Image|startswith: 'C:\Program Files\Microsoft Office\root\Office16\OUTLOOK.EXE'
  selection_powershell:
    CommandLine|contains: 'powershell.exe'
    CommandLine|contains: '-ExecutionPolicy Bypass'
    CommandLine|contains: '-WindowStyle Hidden'
  selection_encoded:
    CommandLine|contains: '-EncodedCommand'
    CommandLine|base64: '*'
  condition: selection_process and selection_powershell and selection_encoded
falsepositives:
  - Legitimate administration tasks using PowerShell from Outlook
level: high
```

### Résumé exécutif

Le 15 novembre 2024, deux incidents simultanés ont été détectés affectant l'infrastructure de l'entreprise :

1. **Attaque SQLi exfiltrative** sur le serveur de production `web-01` depuis l'adresse IP `203.0.113.42`, entraînant l'exfiltration de 2.3MB de données clients via des requêtes vers `/admin/export?table=customers&format=sql`.

2. **Infection par malware PowerShell** sur le poste de travail `PC-COMPTA-07` de l'utilisateur `CORP\\m.durand`, suite à l'ouverture d'une pièce jointe facture frauduleuse (`facture_2024-11.ps1`) depuis Microsoft Outlook.

### Chronologie des événements

| Date/Heure | Événement | Système |
|------------|-----------|---------|
| 15/Nov/2024 18:12-23:21 | Activité SQLi depuis 203.0.113.42 | web-01 |
| 15/Nov/2024 23:15-23:21 | Téléchargement de fichiers de backup | web-01 |
| 16/Nov/2024 08:41-08:42 | Exécution script PowerShell depuis Outlook | PC-COMPTA-07 |
| 16/Nov/2024 08:42 | Isolation du poste par l'astreinte | PC-COMPTA-07 |

### Indicateurs de compromission (IOC)

**Réseau :**
- Adresse source : `203.0.113.42`
- Domaine C2 : `malicious-domain.ru`
- URLs de téléchargement : `http://192.168.1.100/stage1.ps1`, `http://192.168.1.101/beacon.exe`

**Hôte :**
- Fichier : `facture_2024-11.ps1` (SHA256: `064a9a9fe8a517182768cf13f407edc1bf6292ef0b9aa309d3db1cd753d66f40`)
- Processus : `powershell.exe` avec `-ExecutionPolicy Bypass -WindowStyle Hidden`
- Clé de registre : `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`
- Tâche planifiée : `WindowsUpdateTask`

**Application :**
- Endpoints ciblés : `/admin/export`, `/api/login` (brute force), `/upload`
- Modèles de requête : Patterns SQL injection `OR '1'='1'`, `AND 1=1`, `UNION SELECT`

### Attribution technique

Les deux incidents présentent des caractéristiques cohérentes avec une campagne d'attaque coordonnée :
- Utilisation de techniques SQLi pour l'accès initial et l'exfiltration
- Distribution de malware via phishing email avec pièce jointe obfusquée
- Mise en place de mécanismes de persistance (registre, tâches planifiées)
- Tentatives de connexion vers infrastructure C2 contrôlée par l'attaquant

Le même acteur menacant est probablement responsable des deux vecteurs, suggérant une attaque à plusieurs fronts visant à la fois l'infrastructure web et les postes de travail utilisateurs.

### Recommandations immédiates

1. Valider et exécuter les actions de confinement listées ci-dessus
2. Effectuer une analyse forensique complète du serveur web `web-01`
3. Réaliser une formation sensibilisation phishing pour les utilisateurs concernés
4. Mettre à jour les règles de détection Sigma/YARA avec les IOC identifiés
5. Effectuer un audit des accès administrateurs et des privilèges
